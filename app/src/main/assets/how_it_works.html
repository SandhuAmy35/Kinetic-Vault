A digital image is a grid of pixels. Each pixel stores red, green and blue amounts. An amount from 0 to 255 fits into eight binary digits, called bits.

1. Meet the lowest bit

The red channel starts at 100. Its last bit is the least significant bit (LSB): changing it changes the amount by just one.

01100100

Red: 100 · hidden bit: 0

2. Spread bits across colours

Kinetic Vault replaces the lowest bit in red, green and blue. That carries three bits per pixel. The colour difference is usually too small to notice, but the original pixel values still matter.

Red → 1 bitGreen → 1 bitBlue → 1 bit

Standard mode visits pixels in order. Ghost mode scatters payload pixels in a repeatable order. Both keep a public vault header at the start.

3. Encrypt before hiding

Your gesture and optional passphrase derive the encryption key using PBKDF2. Reveal reads the original pixels, reconstructs the encrypted bytes and authenticates them before showing the secret.

A human-chosen gesture can be easy to guess. Add a strong passphrase. Ghost mode changes placement; AES-GCM provides the protection.

4. Keep the original PNG

Send the PNG as a Document/File. JPEG conversion, image compression, resizing, filters and screenshots can destroy the bits. A camera photograph cannot reliably preserve them.

What Scanner tells you

Scanner looks for a valid Kinetic Vault header. Finding one is structural detection, not proof that the secret is authentic. Reveal establishes authenticity by decrypting successfully.

An X-ray brightens each lowest bit to show patterns. Patterns are not proof of hidden data. Kinetic Vault only decrypts images made by Kinetic Vault; it is not a universal steganography detector.

Wrong credentials and damaged data can produce the same unlock failure. The public signature makes vault images detectable.
